# File Management System

A file management system built using **React** and **Django**.  
The system supports chunk-based file uploads, asynchronous processing using **Celery**, real-time progress updates using **WebSockets**, and **Google Drive integration** for file migration.

## Tech Stack

- **Frontend:** React, Vite, JavaScript
- **Backend:** Django, Django REST Framework
- **Background Tasks:** Celery
- **Real-time Communication:** WebSockets
- **Storage Integration:** Google Drive API
